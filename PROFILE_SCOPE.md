# Profile Scope

This repository is the public GitHub profile surface for Ares Yeghiyayan.

Its job is simple: make the profile clear, credible, and easy to understand without turning it into a full project repository.

## What Belongs Here

- Profile README improvements
- Public proof links
- Short notes about build rhythm
- Lightweight profile maintenance
- Changelog updates
- Simple templates and guardrails

## What Does Not Belong Here

- Private research
- Sensitive assumptions
- Internal naming systems
- Detailed workflows
- Private prompts
- Proprietary methods
- Performance claims
- Financial advice claims
- Production readiness claims

## Operating Rule

This repository should stay small.

Every change should make the profile clearer, safer, or easier to trust.

If a change needs depth, it belongs in a dedicated public proof repository instead of this profile repository.

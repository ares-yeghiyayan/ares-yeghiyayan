# Review Path

This page helps readers review the profile quickly.

## Start Here

1. Read `README.md`.
2. Open `PROOF_INDEX.md`.
3. Open `READING_ORDER.md`.
4. Open the public proof repository.
5. Look for small work, review rhythm, safe boundaries, and clean documentation.

## Main Signal

```text
small work -> review discipline -> quality before claim -> safe boundary -> repeatable proof
```

## What To Look For

- small reviewable changes
- clear notes
- safe boundaries
- issue and pull request rhythm
- clean changelog habits

## Boundary

Private work stays outside this profile surface.

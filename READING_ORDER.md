# Reading Order

This profile is designed to be read quickly.

## Start Here

1. Read the profile README.
2. Open `REVIEW_PATH.md`.
3. Open the proof index.
4. Review the profile scope.
5. Open the public proof repository.
6. Look for recent issue, pull request, CI, checkpoint, and changelog activity.

## What To Notice

The important signal is not a single large claim.

The important signal is repeated small work that is easy to inspect.

The strongest pattern to look for is:

```text
small work -> review discipline -> quality before claim -> safe boundary -> repeatable proof
```

## Boundary

This reading order is for public profile navigation only. Private work is not part of this profile surface.

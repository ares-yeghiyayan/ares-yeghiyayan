# Reading Order

This profile is designed to be read quickly.

## Start Here

1. Read the profile README.
2. Open the proof index.
3. Review the profile scope.
4. Open the public proof repository.
5. Look for recent issue, pull request, CI, and changelog activity.

## What To Notice

The important signal is not a single large claim.

The important signal is repeated small work that is easy to inspect.

## Boundary

This reading order is for public profile navigation only. Private work is not part of this profile surface.

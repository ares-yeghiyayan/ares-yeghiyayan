# Profile Maintenance

This note keeps the profile repository small and clean.

## Keep

- short notes
- clear links
- proof navigation
- changelog updates

## Avoid

- long reports
- extra files with no purpose
- broad claims
- unfinished notes
- unnecessary daily changes

## Rule

Each change should improve one narrow part of the profile.

## Daily Noise Rule

This repository should not be updated just to create activity. A profile change is useful only when it improves navigation, clarity, safety, or public proof discipline.
